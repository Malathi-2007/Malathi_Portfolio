+ Nifty 100 Financial Analytics & Investment Intelligence Platform +

Project Objective

The Nifty 100 Financial Analytics & Investment Intelligence Platform is a comprehensive financial data analytics project designed to analyze the financial performance, business fundamentals, market data, and financial health of Nifty 100 companies.

The main goal of this project is to transform complex financial datasets into meaningful and easy-to-understand insights using Python, SQL, SQLite, data analysis, visualization, and machine learning.

The project helps users analyze companies, compare financial performance, study sectors and peer groups, screen companies using financial metrics, and understand important trends in company fundamentals.

Project Summary

This project involves:

  • Collecting and organizing financial data from multiple datasets.
  • Storing and managing structured financial information using SQLite.
  • Cleaning, preprocessing, and transforming financial data using Python and Pandas.
  • Analyzing important financial KPIs and company fundamentals.
  • Performing company, sector, peer-group, and market-cap analysis.
  • Calculating growth metrics such as Revenue CAGR and Free Cash Flow CAGR.
  • Applying K-Means clustering to identify companies with similar financial characteristics.
  • Developing REST APIs using FastAPI to provide structured access to financial data.
  • Building financial screening and comparison functionality.
  • Generating analytical reports and visualizations to communicate financial insights.

    • The final outcome is an analytical platform that combines financial data management, data analytics, machine learning, APIs, and reporting into a single project.

                                            + Self-Driving Car Lane Detection using Computer Vision +

                                            Project Objective

                                            The Self-Driving Car Lane Detection project focuses on applying Computer Vision and Deep Learning techniques to automatically detect lane boundaries on roads.

                                            The main goal is to assist autonomous vehicles in safe navigation by identifying lanes in real time from video input, even under varying lighting and road conditions.

                                            Project Summary

                                            This project demonstrates the process of:

                                            • Capturing and processing road video frames using OpenCV
                                            • Applying edge detection and region masking to highlight lanes
                                            • Using Hough Line Transform and CNN models to detect and mark lane lines
                                            • Visualizing detected lanes on each frame for smooth, real-time feedback

                                              • The outcome is a lane detection pipeline capable of processing live or recorded driving footage and identifying road boundaries accurately.

                                              Technologies Used

                                              • Programming Language: Python
                                              • Libraries: OpenCV, NumPy, Matplotlib, TensorFlow
                                              • Tools: Google Colab

                                                • Implementation Overview

                                                  1. Data Collection

                                                  Collected real-world driving videos and road images from open datasets. Data represented various road types, lighting, and weather conditions to ensure robustness.

                                                  2. Data Preparation

                                                • Converted color frames to grayscale to simplify computations
                                                • Applied Gaussian Blur to reduce image noise
                                                • Used Canny Edge Detection to extract lane boundaries
                                                • Defined a Region of Interest (ROI) to focus on the road area only

                                                  • 3. Lane Detection Logic

                                                • Implemented Hough Line Transform to identify lane edges
                                                • Grouped and averaged detected lines to create continuous lane markers
                                                • Overlaid detected lanes on the original video frames

                                                  • 4. Deep Learning Enhancement

                                                  Integrated Convolutional Neural Networks (CNNs) to improve detection accuracy under complex conditions such as faded lines, shadows, or curves

                                                  5. Visualization & Output

                                                  Visualized lane boundaries in real time using OpenCV and plotted performance results using Matplotlib.

                                                  Analytical Value

                                                    This project simulates the core vision system of autonomous vehicles, demonstrating how computer vision and AI can enable real-time environmental understanding.
